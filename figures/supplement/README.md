# Supplement figures

Figure list:
- `S1_bad_locations.pdf`: mortality data for excluded states
- `S2_synthetic_experiment_exp.pdf`: synthetic experiment (Exponential truth)
- `S3_synthetic_experiment_rational.pdf`: synthetic experiment (Rational truth)
- `S4_final_fits_exp.pdf`: Baseline vs Exponential fits
- `S5_final_fits_rational.pdf`: Baseline vs Rational fits
- `S6_r0_final_size_exp.pdf`: $R_0$ and final size (Baseline vs Exponential)
- `S7_r0_final_size_rational.pdf`: $R_0$ and final size (Baseline vs Rational)
- `{S9, S10, S11}_beta_eff_{model_name}.pdf`: effective transmission rates $\beta_{eff}(t)$
- `{S12, S13, S14}_r_effective_{model_name}.pdf`: effective reproduction numbers $R_e(t)$

Generated by the R scripts:
- `R/plot_bad_locations.R`
- `R/plot_fits_data.R`
- `R/plot_r0_and_final_size_boxplots.R`
- `R/plot_synthetic_results.R`
- `R/plot_beta_eff_all.R`
- `R/plot_re_eff_all.R`

Note: the PDF files are not tracked by version control to keep the repository lightweight.
