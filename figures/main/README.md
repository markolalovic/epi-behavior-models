# Main figures

Figure list:
- `F1_final_fits_mixed.pdf`: model fits (Baseline vs Mixed) across 30 locations
- `F2_r0_final_size_mixed.pdf`: comparison of $R_0$ and final epidemic size
- `F3_synthetic_experiment_mixed.pdf`: synthetic data experiment results (Mixed truth)

Generated by the following R scripts:
- `R/plot_fits_data.R`
- `R/plot_r0_and_final_size_boxplots.R`
- `R/plot_synthetic_results.R`

Note: the PDF files are not tracked by version control to keep the repository lightweight.
