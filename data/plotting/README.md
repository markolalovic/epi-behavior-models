# Plotting data
- `r0_boxplot_data.csv` and `final_size_boxplot_data.csv`: 
  * Statistics produced by `src/create_r0_data.py` and `src/create_final_epi_size_data.py` for boxplot figures 
  * Used by `R/plot_r0_and_final_size_boxplots.R`, and by `R/generate_tables.R` to generate tables.

- `synthetic_true_*.csv` are ground truth values produced by `src/calculate_synthetic_r0_and_final_sizes.py` and used by `R/plot_synthetic_results.R` to show the red "truth" lines.

- `order_*.csv` are used by `R/plot_fits_data.R` script to generate the figures exactly as they appear in the paper.
